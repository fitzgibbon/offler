offler — a unified graphics, windowing and audio library for Idris 2

Each example runs on WebGL2 and WebGPU from the same source, and the same source also builds a native binary on SDL3 + wgpu-native. Build the bundles with make web.

  • Shapesrotating lit primitives — bevy's 3d_shapes
  • Lineswireframe globe, Lissajous ribbon, grid — line-list rendering
  • Swarm50 000 bodies in one instanced draw around a glowing core
  • Customa user-defined hologram material — Blend, Mask, the Material interface
  • Flat 2Dorthographic, unlit — the 2D mode
  • Chimesynthesised sound + every input: touch, gamepad, pointer lock
